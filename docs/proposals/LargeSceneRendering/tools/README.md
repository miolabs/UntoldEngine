# Tools of the large-scene work

Scratch files kept here because the session scratchpad is wiped on a restart. None is part of the engine.

- `psnr.swift`: stand-in for `Tests/UntoldEngineRenderTests/Resources/compare_psnr.py` on a Mac without OpenCV and scikit-image. Build with `xcrun swiftc -O -o psnr psnr.swift`; run the render suite with `UNTOLD_PYTHON=<path>/psnr CI=true`. `PSNR_LOG=<file>` appends every value.
- `BimPlainBenchmark.swift`: drop into `Tests/UntoldEngineRenderTests/` of any checkout at or after upstream develop `4ae99ca2`; prints a `BIMBENCH` line per view. Release build with `-Xswiftc -enable-testing -Xswiftc -DENGINE_STATS_ENABLED`, then `BIM_PACK=<pack path without extension> BIM_TAG=<name> BIM_VIEWS='<the six views>' swift test -c release --skip-build --filter BimPlainBenchmark`. The six BIM views: `overview=283,291,285>-61,9,-59;walk=40,1.7,60>86,2,-24;grove=116.6,6,6.2>86.6,1.5,-23.8;tree3m=87.6,1.6,149.8>84.6,2.0,147.8;tree15m=97.6,1.7,155.3>84.6,2.0,147.8;tree40m=119.2,1.7,167.8>84.6,2.0,147.8`. Compare two builds by running them in turn, three rounds.
- `BimPackBenchmark.swift`: the full form for the instancing, walks and batching branches (`BIM_BATCH=loader`, `BIM_INSTANCING=0`, `BIM_MODES`, the probes).
- `ZZScreenSizeSheet.swift` + `compose_lod_screen_size.py`: the panels and the sheet of the LOD-by-screen-size pull request (`SHEET_OUT=<folder> swift test --filter ZZScreenSizeSheet` in the screen-size branch, then the script).
- `resolve_conflicts.py <file> <policy[,policy…]>`: resolves the conflict blocks of a file in order with `ours`, `theirs`, `both` or `theirs-ours`.
- `ZZHeadsetFindings.swift`, `ZZCarLevels.swift`: the two experiments of 2026-10-07 on the headset findings (the occlusion test under motion; every parked car at a forced level). `BIM_PACK=<pack> BIM_OUT=<folder> swift test -c release --skip-build … --filter ZZHeadsetFindings` (or `ZZCarLevels`) in a release build with the statistics.
- `ZZWhiteCar.swift.txt`, `ZZCarLevels.swift.txt` (render tests, in a worktree with the snapshot branch): the whitest parked car of the BIM site close up at a forced level, with `KEEP_MESHES`/`HIDE_MESHES` (comma-separated name substrings), `ONLY_LEVEL`, `NO_NODARK`, `TAG`; and every car at each level. `BIM_PACK=<pack> BIM_OUT=<folder> CI=true swift test --skip-build --filter ZZWhiteCar`.
- `ZZCarLevelMeshes.swift.txt` (engine tests): per-mesh triangle counts of two level files of one model (`LEVEL_A`, `LEVEL_B`), with `FOCUS=<mesh name>` and `PIECES=1` (triangles per connected piece and the longest edges), `SHELL=<mesh>` (vertices outside a shell by ray parity; unreliable on open shells) or `LEVEL_0=<model>` (vertices off the original surface, inward or outward). How the cars' giant polygons were traced to a sunk piece starving the rest of its mesh (2026-10-08).
- `ZZCarPieces.swift.txt`, `ZZCarRegion.swift.txt`, `ZZCarMaterials.swift.txt`, `ZZCookPack.swift.txt` (engine tests): the hidden pieces of a model and how they are sunk (`BIM_MODEL`); the meshes overlapping a region (`REGION=x0,x1,y0,y1,z0,z1`); the materials of a model's meshes; a re-cook of a pack copy with timing (`BIM_PACK`). The debug build is too slow for the car model (minutes): run through `xcrun xctest -XCTest UntoldEngineTests.<Class>/<method> .build/out/Products/Debug/UntoldEngineTests.xctest`, which takes no SwiftPM build lock.
- `ZZWriteSheetModels.swift.txt` (engine tests, `SHEET_DIR`) + `ZZHiddenSheet.swift.txt` (render tests, `SHEET_PLAIN`, `SHEET_NEW`, `SHEET_OUT`): the synthetic models of the hidden-parts pull request's sheet (a roof over a dark lining, a dark shell inside a white one), cooked with two CLIs (`untoldengine bake-lods --input <model>`), drawn at the coarsest level. The sheet itself was composed with PIL in a scratch script (four panels with labels).
